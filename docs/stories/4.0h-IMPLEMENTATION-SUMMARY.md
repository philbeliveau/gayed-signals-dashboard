## 🚀 How to Enable Railway Backend

### Development
```bash
# In apps/web/.env.local
NEXT_PUBLIC_RAILWAY_BACKEND_URL=https://gayed-signals-backend-production.up.railway.app
RAILWAY_API_KEY=your_railway_api_key
NEXT_PUBLIC_USE_RAILWAY_BACKEND=true
```

### Production (Vercel)
```bash
# Set environment variables in Vercel dashboard
NEXT_PUBLIC_RAILWAY_BACKEND_URL=https://gayed-signals-backend-production.up.railway.app
RAILWAY_API_KEY=your_railway_api_key
NEXT_PUBLIC_USE_RAILWAY_BACKEND=true
```

## 📈 Performance Metrics

### Target Performance
- **Cached responses:** <500ms (Railway Redis)
- **Fresh data requests:** <2s (Railway PostgreSQL)
- **Fallback to local API:** <3s total
- **Connection timeout:** 10s
- **Retry attempts:** 3 with exponential backoff

### Monitoring
Access performance stats via:
```typescript
import { performanceMonitor } from '@/lib/api/performance-monitor';

const stats = performanceMonitor.getStats();
console.log(stats.railwaySuccessRate); // Railway success rate
console.log(stats.cacheHitRate);       // Cache hit percentage
console.log(stats.averageDuration);    // Average response time
```
