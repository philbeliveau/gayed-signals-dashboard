## Story

**As a** trader using the backtesting platform,
**I want** to select custom Risk-On and Risk-Off ETF symbols for my backtests,
**so that** I can test strategies with different indexes (e.g., QQQ instead of SPY, or leveraged/international ETFs)

## Acceptance Criteria

2. [x] User can select custom Risk-Off symbol from dropdown (defaults to signal's standard symbol)
3. [x] Dropdowns show common ETF options organized by category (US Equity, Defensive, Sectors, International, Leveraged)
4. [x] Custom symbols work with all 5 signal types
5. [x] Default behavior unchanged when no custom symbols selected
6. [x] Invalid symbols show clear error message
7. [x] Works on mobile devices (responsive design maintained)
8. [x] Railway backend validation handles custom symbols automatically

## Technical Notes

### Integration Approach

**Follows Existing Pattern:**
- Date range selection already uses dropdown pattern (page.tsx:~145-165)
- Form validation already exists for required fields
- Railway backend already handles arbitrary symbols via UnifiedDataService
- Quality validation (minimum 0.8 score) automatic

**Implementation Strategy:**
```typescript
// page.tsx - Add to state
const [riskOnSymbol, setRiskOnSymbol] = useState<string>('');
const [riskOffSymbol, setRiskOffSymbol] = useState<string>('');

// SignalAdapter.ts - Update getPositionSymbol()
static getPositionSymbol(
  signalType: SignalType,
  position: Position,
  customRiskOn?: string,
  customRiskOff?: string
): string {
  if (customRiskOn && position === 'RISK_ON') return customRiskOn;
  if (customRiskOff && position === 'RISK_OFF') return customRiskOff;

  const config = SIGNAL_CONFIGS[signalType];
  return position === 'RISK_ON' ? config.riskOnSymbol : config.riskOffSymbol;
}
```

### Signal-Specific ETF Options

**NOTE:** ETF options are filtered based on the selected signal type to show only contextually relevant choices. **These options match the dashboard ETF recommendations** from `apps/web/src/app/page.tsx` (lines 93-425).

**Utilities/SPY Signal:**
- Risk-On: SPY (default), QQQ, IWM, SPXL (3x leveraged)
- Risk-Off: XLU (default), SPLV (low volatility), USMV (min volatility)
- **Note:** Focuses on defensive utilities vs equity exposure

**Lumber/Gold Signal:**
- Risk-On: WOOD (timber/forestry - used for signal calc), XLI (industrials), XLB (materials), IYM (basic materials)
- Risk-Off: GLD (default), IAU (gold trust), TLT, PDBC (commodities)
- **Note:** Commodity-focused with lumber and gold tracking

**Treasury Curve Signal:**
- Risk-On: IEF (7-10yr Treasury - used for signal calc), SHY (1-3yr Treasury), VTEB (municipal bonds)
- Risk-Off: TLT (20+ yr Treasury - default), EDV (extended duration), VGLT (long-term Treasury)
- **Note:** Yield curve steepness strategy (IEF vs TLT)

**SP500 Moving Average:**
- Risk-On: SPY (default), SPXL (3x leveraged), QQQ, VTI (total market)
- Risk-Off: SHY (1-3yr Treasury - default), TLT, SPLV (low volatility), VMOT (multi-asset)
- **Note:** Equity trend following (SPY vs 200-day MA)

**VIX Defensive Signal:**
- Risk-On: SPHB (high beta - default), SPXL (3x S&P 500), TQQQ (3x Nasdaq), UPRO (3x S&P 500)
- Risk-Off: SPLV (low volatility - default), USMV (min volatility), VXX (VIX futures), VIXY (VIX futures)
- **Note:** Volatility-based strategy (uses VIXY for signal calc)

**Signal Adapter Update (SignalAdapter.ts):**
```typescript
static getPositionSymbol(
  signalType: SignalType,
  position: Position,
  customRiskOn?: string,
  customRiskOff?: string
): string {
  // Use custom symbols if provided
  if (customRiskOn && position === 'RISK_ON') return customRiskOn;
  if (customRiskOff && position === 'RISK_OFF') return customRiskOff;

  // Fallback to default configuration
  const config = SIGNAL_CONFIGS[signalType];
  return position === 'RISK_ON' ? config.riskOnSymbol : config.riskOffSymbol;
}
```
