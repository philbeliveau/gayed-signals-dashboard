## Story

**As a** trader,
**I want** a simple backtesting platform for the 5 Gayed signals,
**so that** I can test how each signal would have performed historically by trading their associated ETFs

1. [ ] Platform supports all 5 Gayed signals (Utilities/SPY, Lumber/Gold, Treasury Curve, SP500 MA, VIX Defensive)
2. [ ] Uses ONLY real market data from Railway backend - no synthetic data
3. [ ] Implements simple position switching logic (Risk-On ETF vs Risk-Off ETF)
4. [ ] Calculates basic performance metrics (total return, number of trades, max drawdown, win rate)
5. [ ] Displays equity curve chart showing portfolio value over time
6. [ ] Shows complete trade history with dates and reasons
7. [ ] Works with any user-selected date range
8. [ ] No complex calculations - just signal → position → track performance

## Dev Notes

### Core Architecture Principle
This is a SIMPLE backtesting system. No synthetic data, no complex calculations, no correlations. Just:
1. Fetch real prices
2. Calculate signal (using existing calculators)
3. Determine position
4. Track performance

### Reusing Existing Signal Calculators
All 5 Gayed signal calculators already exist in `domains/data-pipeline/src/engines/signal-calculators/`:
- `utilities-spy.ts` - GayedSignalCalculator.calculateUtilitiesSignal()
- `lumber-gold.ts` - GayedSignalCalculator.calculateLumberGoldSignal()
- `treasury-curve.ts` - GayedSignalCalculator.calculateTreasuryCurveSignal()
- `sp500-ma.ts` - GayedSignalCalculator.calculateSP500MASignal()
- `vix-defensive.ts` - GayedSignalCalculator.calculateVixDefensiveSignal()

**DO NOT recreate these!** Just import and use them.

### Signal Trading Rules

```typescript
// Utilities/SPY Signal
if (XLU/SPY > threshold) {
  position = 'XLU';  // Risk-Off
} else {
  position = 'SPY';  // Risk-On
}

// Lumber/Gold Signal
if (WOOD/GLD > threshold) {
  position = 'SPY';  // Risk-On
} else {
  position = 'GLD';  // Risk-Off
}

// Treasury Curve Signal
if (IEF/TLT > threshold) {  // Curve steepening
  position = 'SPY';  // Risk-On
} else {
  position = 'TLT';  // Risk-Off
}

// SP500 Moving Average
if (SPY > MA200) {
  position = 'SPY';  // Risk-On
} else {
  position = 'IEF';  // Risk-Off
}

// VIX Defensive
if (VIXY < threshold) {  // Using VIXY ETF as proxy for VIX
  position = 'SPY';  // Risk-On
} else {
  position = 'TLT';  // Risk-Off
}
```

### Data Requirements
Symbols needed from Railway backend:
- SPY (S&P 500 ETF)
- XLU (Utilities ETF)
- WOOD (Lumber ETF)
- GLD (Gold ETF)
- IEF (7-10 Year Treasury ETF)
- TLT (20+ Year Treasury ETF)
- VIXY (VIX ETF - Note: Use VIXY not ^VIX as Tiingo doesn't support ^VIX)

**Data Fetching Pattern:**
```typescript
// ✅ CORRECT: Use MarketDataV2Service wrapper (Task 2A)
import { MarketDataV2Service } from '@/lib/api/market-data-v2';

const marketDataService = new MarketDataV2Service();
const response = await marketDataService.getMarketData({
  symbols: ['SPY', 'XLU', 'WOOD', 'GLD', 'IEF', 'TLT', 'VIXY'],
  startDate: '2024-01-01',
  endDate: '2024-11-01'
});

// Automatic quality validation, provenance tracking, Railway → Local fallback

// ❌ WRONG: Direct Railway fetch (bypasses Railway wrapper pattern)
const data = await fetch(`${RAILWAY_BACKEND_URL}/api/v2/market-data`, ...);
```

### Railway Backend Integration

**Railway Response Structure (API Contract for Task 0)**

**Endpoint:** `POST /api/v2/market-data`

**Request:**
```typescript
{
  symbols: string[];      // ['SPY', 'XLU', 'WOOD', 'GLD', 'IEF', 'TLT', 'VIXY']
  startDate: string;      // ISO date: '2023-01-01'
  endDate: string;        // ISO date: '2024-01-01'
}
```

**Response (MarketDataResponse):**
```typescript
{
  success: boolean;
  data: Array<{
    symbol: string;
    date: string;         // ISO date
    open: number;
    high: number;
    low: number;
    close: number;
    volume: number;
  }>;
  metadata: {
    source: 'tiingo' | 'postgresql' | 'redis';
    quality: {
      score: number;      // 0-1 scale (minimum 0.8 enforced by backend)
      issues: string[];   // Empty if quality.score >= 0.8
    };
    timing: {
      totalMs: number;
      cached: boolean;
    };
    provenance: {
      dataProvider: string;
      fetchedAt: string;  // ISO timestamp
      dataPoints: number;
    };
  };
}
```

**Error Response:**
```typescript
{
  success: false;
  error: string;
  metadata: {
    source: 'error';
    quality: { score: 0, issues: [error_details] };
  };
}
```

### Position Sizing
- Always 100% in one ETF (no partial positions)
- No leverage, no shorting
- Simple buy and hold until signal changes

### Performance Calculation
```typescript
interface BacktestResult {
  totalReturn: number;      // (finalValue / initialValue - 1) * 100
  numberOfTrades: number;    // Count of all buy/sell transactions
  winRate: number;          // profitableTrades / totalTrades * 100
  maxDrawdown: number;      // Largest peak-to-trough decline
  trades: TradeRecord[];    // Complete history
  equityCurve: {           // Daily portfolio values
    date: string;
    value: number;
  }[];
}
```

### Testing

#### Test Requirements
- Test with known historical period (e.g., 2023 full year)
- Verify signal calculations match expected values
- Ensure trades execute only when signals change
- Validate performance metrics calculation
- Test with periods of missing data (should fail gracefully)

#### Test Data Validation
```typescript
// Ensure data quality from Railway
if (data.metadata.quality.averageScore < 0.8) {
  throw new Error('Data quality too low for reliable backtesting');
}

// Validate all required symbols present
const requiredSymbols = ['SPY', 'XLU', 'WOOD', 'GLD', 'IEF', 'TLT', 'VIXY'];
for (const symbol of requiredSymbols) {
  if (!data[symbol]) {
    throw new Error(`Missing data for ${symbol}`);
  }
}
```

### Critical Implementation Rules

1. **NO SYNTHETIC DATA** - If real data unavailable, fail with clear error
2. **SIMPLE LOGIC ONLY** - No correlations, no complex statistics
3. **ONE POSITION AT A TIME** - Always 100% in one ETF
4. **CLEAR TRADE REASONS** - Each trade must log why it happened
5. **USE RAILWAY BACKEND** - All data through Railway, no direct API calls
